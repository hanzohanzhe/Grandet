# Roadmap / 计划

## Skill and Personal / Skill 与个人版

- [x] Publish Grandet Skill 0.3.0 as a public preview. / 发布 Skill 0.3.0 公开试用版。
- [x] Install once, then use it in later conversations. / 装一次，以后的对话都能用。
- [ ] Test installation and fresh-conversation use in every app listed in the install guide. / 在安装指南列出的每个应用里测完安装和新对话使用。
- [ ] Improve first answers based on preview feedback, keeping recommendations short and clear. / 根据试用反馈改进首次回答，推荐保持简短清楚。
- [ ] Continue the Grandet Personal private beta: key management, routing and fallback, spending records, speed and quality comparison. / 继续个人版私测：Key 管理、路由回退、费用记录、速度和质量对比。
- [ ] Release a public Personal installer after desktop testing, then connect the Skill to it. / 桌面端测完后发布个人版安装包，并与 Skill 打通。

## Catalogue / 目录

- [x] Zero-dependency validator, reproducible Markdown and a local browser view. / 零依赖校验器、可复现的 Markdown 和本地浏览页。
- [x] Keep every field of the 73 official and 34 third-party records. / 完整保留 73 条官方和 34 条第三方记录。
- [x] Attribute each record and keep source rights separate from Grandet's compilation. / 每条记录注明出处，来源权利与 Grandet 汇编分开。
- [x] Launch the website with HTTPS; see [website status](WEBSITE-STATUS.json). / 官网已上线，见[网站状态](WEBSITE-STATUS.json)。
- [ ] Accept sourced corrections and cover more regions and languages. / 接受带来源的更正，扩大地区和语言覆盖。
- [ ] Add reviewed machine-readable eligibility and date checks, without inventing missing conditions. / 增加经审核的资格与时间校验，不补造缺失条件。
- [ ] Review and release selected client modules under their actual licences. / 审核后按实际许可公开部分客户端模块。
- [ ] Turn on regular data updates only after a reviewed workflow is in place. / 更新流程审核通过后再开启定期数据更新。

Dates and milestones are plans, not promises. This repository contains no client binary. / 时间和里程碑是计划，不是承诺。本仓库不含客户端程序。
